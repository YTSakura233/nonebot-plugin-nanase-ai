# Rating、DX分、失分与B50代码使用

本包提供原创Python模块examples/maimai_math.py，仅依赖标准库。输入达成率使用百分比单位，参数可传字符串，以保留十进制精度。

```python
from examples.maimai_math import rating, dx_score, achievement_loss
print(rating('13.7', '100.5'))
# (308, 'SSS+')
print(dx_score(450, 40, 8, 1, 1))
# {'score': 1438, 'maximum': 1500}
notes = {'tap': 100, 'hold': 10, 'slide': 10, 'touch': 20, 'break': 5}
print(achievement_loss(notes, 'break', 'p50'))
# Decimal('0.05')，即损失0.05个百分点
```

## 为什么使用Decimal

展示的100.4999、100.5和向下取整都是十进制边界。Decimal从字符串构造，可以直接表达这些值；不要先经过float四舍五入到100.5再计算，否则提前跨档。[Python Decimal说明](https://docs.python.org/3/library/decimal.html)

所用Rating档位来自水鱼固定版本社区算法，不是对所有查分服务的统一担保。模块包含特殊边界与低分分档，保留到最终结果才向下取整。若目标接口已经返回单谱dx_rating或ra，应先确认它是否已经取整，以及与本地算法的版本关系。

## B50输入的责任

best50(records)需要每条含song_id、type、difficulty、ds、achievements、is_new。is_new必须是布尔值，不能把字符串"false"当作True。程序对相同谱面键去重，分别取旧35与新15，过滤utage；调用者仍需先剔除禁用、未配信和无授权数据。

不能只传达成率就计算Rating，定数和算法版本是必需的。计算本人提升建议时，最好同时给出当前池末位和目标分数；否则只能返回单谱估算，不能承诺总分增加多少。
