# 曲库采集、差异检查与可重现更新

本包保留三份上游快照：落雪歌曲、落雪别名、国服NET社区显示等级。生成器不访问网络，更新器只访问固定公开地址。未知字段保留在原始资料；无法识别的结构先报错，不静默生成虚假默认值。

## 常用命令

```bash
# 包根目录，离线重建Markdown、JSON索引和manifest
python scripts/build_pack.py
# 离线检查资料完整性、算例与文档上限
python scripts/validate_pack.py
# 下载候选并验证，保留现有发布文件
python scripts/refresh.py --game-version 25500 --dry-run
# 先保存上一个ZIP，停止机器人导入，再实际刷新
python scripts/refresh.py --game-version 25500
```

refresh先把三份资料全部下载、解析、校验，再在临时目录构建候选。--dry-run不会替换已发布文件；实际发布为多文件复制，不是数据库事务，发布期间停止机器人，完成后重新校验再启动。不要在模型工具循环里自动调用更新脚本。

## 本包实际检查

歌曲ID唯一、常规难度索引唯一、数值有限且合法、显示等级格式、配信日期格式、具名物量非负且分项和一致、BUDDY左右结构、同名曲艺术家消歧、别名引用不存在ID的清单、两源等级差异、每个文件的SHA-256，以及插件200文档/20000片段/单文档4MiB限制。

新快照歌曲条目若减少超过10%，更新器拒绝直接发布，要求人工检查来源。它不是断言删曲不可能超过10%，而是保护旧快照不被异常小响应覆盖。HTTP成功也不能证明JSON完整；本次采集曾遇到公开镜像JSON截断，该镜像未纳入交付数据。

## 去掉文件后的数据库处理

ナナセ当前导入器对同一collection/source覆盖写入，但磁盘删除不会自动删除数据库旧来源。更新导致generated文件减少或集合改名时，管理员应按已确认的旧来源清理知识表再重启；不要保留两份不同日期的同名事实却不标日期。日常更新不要改集合名或随意改文件名。
