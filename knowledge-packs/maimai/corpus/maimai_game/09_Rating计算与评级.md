# Rating计算、评级阈值与社区算法版本

DX Rating由新曲与旧曲两个部分组成。官方介绍确认这种分池结构，但没有在该页面公开全部小数公式。[SEGA Rating介绍](https://maimai.sega.com/play/newfunction2/)

本包数学示例采用水鱼2026-08-18源码中的社区计算档：单谱Rating=floor(定数×min(达成率,100.5)/100×系数)。不是SEGA源码声明。[固定版本算法依据](https://github.com/Diving-Fish/maimaidx-prober/blob/01593811b106b50594ed71026b75ba29a74d6806/database/models/maimai.py)

## 常见评级的起点

| 评级 | 达成率起点 | 常用系数 |
| --- | --- | --- |
| A | 80% | 13.6 |
| AA | 90% | 15.2 |
| AAA | 94% | 16.8 |
| S | 97% | 20.0 |
| S+ | 98% | 20.3 |
| SS | 99% | 20.8 |
| SS+ | 99.5% | 21.1 |
| SSS | 100% | 21.6 |
| SSS+ | 100.5% | 22.4 |

这里的常用系数表不能替代完整实现：所选水鱼源码还在79.9999、96.9999、98.9999、99.9999、100.4999等边界使用额外系数；低于50%亦有更细分档。完整表和Decimal计算在examples/maimai_math.py。需要精确复现另一个查分器时，用那个服务自己的算法与版本，不能假定所有实现完全一致。

## 原创算例

定数13.7、达成率100.5时：13.7×1.005×22.4=308.4144，向下取整为308。到101%时仍为308，因Rating计算截在100.5。定数14.0、达成率100%时为302；100.5%时为315。不是每提高0.1%都固定涨一样的Rating。

单谱提升不必然使总Rating提升：若不进入对应池前列，或仍未超过该池末位，它不会替换已有贡献。评级、单谱Rating、总Rating和段位也应分别表述。
