# 舞萌常用术语词典

本词典用于检索扩展和解释社区语言；不同群体可能有不同用法，短词不强制映射到唯一曲目。

| 术语 | 在本库中的理解 |
| --- | --- |
| mai、舞萌、maimai | 游戏系列简称；具体地区版本另查 |
| DX、SD | 可指谱面类型；DX也可能指DX分或游戏名，需看上下文 |
| 绿/黄/红/紫/白 | BASIC / ADVANCED / EXPERT / MASTER / Re:MASTER |
| 标级、等级 | 机台显示的整数或带加号难度字符串 |
| 定数、ds | 社区计算使用的小数难度，来源与版本必须说明 |
| 拟合、fit_diff | 统计估计的难度，不是官方定数替代品 |
| 达成率、acc、achievement | 百分比成绩，常规DX可到101% |
| S、SS、SSS | 评价档；S+、SS+、SSS+须保留加号 |
| 鸟、鸟加 | 常指SSS、SSS+；语境不明确时确认 |
| FC、FC+ | 连击类标记，比百分比描述更具体 |
| AP、AP+ | 全PERFECT类标记，不等于全部CP |
| CP、大P | CRITICAL PERFECT |
| BREAK、绝赞 | 高基础权重且带额外分的属性 |
| 50落、100落 | BREAK精度的社区说法，不是固定百分比损失 |
| DX分、dx_score | 按判定计点的独立指标，满分3×计数物量 |
| B50、Best50 | 常见旧35+新15贡献榜单 |
| 底分、ra | 常指单谱Rating贡献，具体说法看上下文 |
| 推分、上分 | 提升某成绩指标；应明确达成率还是Rating |
| 星星头、滑条头 | SLIDE开始的TAP任务，和轨迹分开处理 |
| 慢滑、快滑 | 轨迹运动时长特征，不等于整曲BPM高低 |
| EACH、双押 | 同时任务，不必恰好只有两颗 |
| BUDDY | 宴会场双人专用谱面形式 |
| PC、cred | 可能指游玩轮次/点数，不同社区含义不完全统一 |

检索策略：用户说“鸟加差一颗绝赞”，先联想到SSS+、100.5%、BREAK额外损失；用户说“这首DX多少”，先判断是在问DX谱等级、DX理论分，还是新曲Rating。不要把“蓝屏”“门”等社区称呼直接当作数据库主键。
