# ナナセ知识库部署与功能边界

将本包保存为机器人工作目录下的maimai-knowledge，配置：

```dotenv
SORUTO_KNOWLEDGE_DIR="./maimai-knowledge/corpus"
SORUTO_KNOWLEDGE_COLLECTIONS=["maimai_game","maimai_songs","maimai_levels","maimai_dev","maimai_project"]
SORUTO_KNOWLEDGE_QUERY_EXPANSION=true
```

相对路径以机器人进程工作目录为基准。用户自定义目录时改成实际路径；不要把本地开发电脑E盘路径直接抄给Linux服务器。

## 启动与导入

现有插件启动时导入已启用集合，源文件按集合与相对路径定位，同源在事务中替换。更新快照后重启加载。导入需要插件已配置可用MySQL/MariaDB；本次开发只验证离线内容，未连接用户数据库执行导入。

单文件手动导入命令是python -m nonebot_plugin_soruto_ai.knowledge import FILE --collection NAME，但手动导入默认来源名与目录启动导入来源可能不同。已采用本包目录导入时，优先维持同一路径方案，避免同一文件以两个来源重复进入数据库。

## 与父项目的关系

父目录nonebot_plugin_maimai有账号操作、绑定、自动登出、游戏更新和查分等功能，其权限与命令规范独立。ナナセ只读这些知识文本，不会因为懂得某命令就自动获得父项目操作权限。父项目的mai.命令也不会自动成为本包MCP工具。

## 当前知识与实时能力

本包覆盖公开规则、采集时曲库和原创开发示例；不含本人最新分数、官方登录态、个人钥匙或付费模型密钥。需要实时歌曲信息时可由允许的搜索工具查询来源，或由管理员刷新公开快照；需要个人数据时应另行实现经过授权的专门接口。

本地说明对应0.1.3。未来代码修改后应更新此集合的版本与行为记录，避免机器人把旧实现回答成当前能力。

独立公开仓库为https://github.com/YTSakura233/nonebot-plugin-nanase-ai，更新分支main，Python导入名仍为nonebot_plugin_soruto_ai。仓库内知识库位于knowledge-packs/maimai，配置目录应指向其corpus；本知识库说明不授予机器人自行执行Git/Shell或修改部署配置的权限。
