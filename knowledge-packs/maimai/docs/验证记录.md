# 验证记录

日期：2026-11-01。Python 3.11.9，现有NoneBot2 2.4.4 / OneBot V11 2.4.6，隔离依赖中MCP SDK 2.3.0。

## 数据与离线检查

python scripts/build_pack.py生成130份Markdown、3313个当前插件片段。1360条落雪歌曲记录、5623张谱面、1294条国服NET曲目、5520张国服NET常规谱面、2933个已关联别名。两源2069处显示等级差异，16个别名ID未匹配，55张尚未配信谱面、1首disabled均明确保留。

python scripts/validate_pack.py通过15项检查，涵盖资料SHA-256、覆盖率、等级索引、同名Link消歧、BUDDY左右物量、配信UTC+8 07:00边界、错误源拒绝、Rating特殊边界、达成率与DX分计算、B50池分离/去重、simai时序及不支持语法、CLI，以及更新dry-run/异常不改变旧资料。

python -m compileall检查examples与scripts语法通过。git diff --check通过，工作区既有文件仅提示LF/CRLF转换提示。

## 真实组件离线集成

scripts/integration_check.py使用现有ナナセ插件实际tokens、chunks与_rank，对七类问题验证top4召回：AP+与DX满分、13.7鸟加贡献、ナナセ凌晨聊天、滑条时序、Oshama Scramble!、真爱歌及水鱼OAuth。

NoneBot成功加载nonebot_song演示，仅注册一个响应器。真实MCP SDK通过本地stdio发现search_song，调用“真爱歌”返回ID8 / True Love Song，关闭后所有worker任务结束。详细召回结果在integration-check.json。

Windows沙箱限制asyncio本地套接字，集成命令在获准的沙箱外执行；验证不连接外部网络、模型、数据库或QQ。没有用这些离线结果声称已完成服务器部署。
